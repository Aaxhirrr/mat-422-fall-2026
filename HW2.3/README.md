## run it

Open the notebook in Colab and choose **Runtime > Run all**. NumPy, Matplotlib, and SciPy are already available there. All 12 checks at the end should print `True`.

The notebook has 11 code cells with saved results and five plots. It includes discrete and continuous joint distributions, marginals, conditional distributions, covariance, correlation, a dependent but uncorrelated example, and random sampling with the law of large numbers and central limit theorem.

The random examples use a fixed seed, so a full run reproduces the same samples. Run from the top again if you rerun individual random-sampling cells and want the original results.
